# 60 Projetos de Equipamentos de Calistenia — página de vendas

Página única em Vite (HTML + CSS + JS, sem dependências de runtime).

- `index.html` — a página inteira. A oferta (preços, bônus, links de checkout, pixel) fica em `window.OFERTA`, no topo.
- `public/` — imagens servidas como estão (`/assets/...`, `/icon-*.webp`).
- Build: `npm run build` → `dist/` · Dev: `npm run dev` (porta 5173).

## Vercel
Framework **Vite** (detectado sozinho) · Build `npm run build` · Output `dist`.
